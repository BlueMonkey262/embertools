# KFMAWI — Fire HD 10 (2019, 9th Gen)

Model-specific mods for this device go in subfolders here (each a `mod.py` with a
`MOD`), and override any `shared/` mod of the same name. Nothing device-specific
is needed yet — every mod this device uses lives in `shared/`.

Status: **fully tested.** launcher_swap (instant redirect), debloat, private_dns
and ota_block all verified on Fire OS 7.3.3.1.
