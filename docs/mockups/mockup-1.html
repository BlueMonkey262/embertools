launcher_swap

available

Set a third-party launcher (Nova, Lawnchair, Kvaesitso) as the instant default without root. embertools installs a tiny accessibility helper that redirects Home to your launcher, and registers it as the device assistant so the redirect fires instantly instead of after Fire OS's ~5 s app-switch delay. Survives reboot.

Must already be installed on the device. Custom… lets you enter a package name.
Recommended. Some Fire OS builds only release the Home role after a restart.
low risk Fully reversible. Revert restores the stock Fire launcher as default.
Ready · will apply to KFMAWI
